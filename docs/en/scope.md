# Scope

ArtifactWeaver is a generic artifacts rendering middleware.

## In Scope For M0

- Render Manifest v1.
- Markdown source.
- Report JSON source.
- Evidence JSON source.
- One static HTML report output.
- Relative path validation.
- Fake examples.
- Bilingual documentation and worker harness.

## Out Of Scope For M0

- YAML input.
- Slides.
- PDF export.
- Node, Bun, Vite, React, Vue, or Slidev renderer backends.
- Unity, Feishu, Jenkins, Steam, Codex, MCP, or private repository integration.
- Test execution, QA judgment, or automatic report discovery.
- NoTimeToDie-specific adapter code.
