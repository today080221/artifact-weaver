# Worker Protocol

## Start

1. Read `HARNESS.md`.
2. Read the issue or task.
3. Read the matching context pack.
4. Confirm allowed paths and out-of-scope paths.
5. Run `git status --short --branch -uall`.
6. Record a start entry when the task requires it.

## During Work

Stay inside the context pack. Record any required scope expansion before touching extra files.

## Done

Run validation, update documentation, update logs, and hand off without committing or pushing automatically.
