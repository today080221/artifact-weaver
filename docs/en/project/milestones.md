# Milestones

## M0 Bootstrap

Create the initial Python-only ArtifactWeaver repository, CLI, manifest contract, HTML report renderer, bilingual documentation, and worker harness.

## M1 Consumer Contract

Stabilize the downstream consumer contract for private projects that generate artifacts and call ArtifactWeaver.

## M2 Report Renderer Polish

Improve the static HTML report renderer, themes, accessibility, and artifact index.

## M3 Slides / PDF Renderer Evaluation

Evaluate optional Node/Vite/Slidev/Playwright based renderers without changing the Python core contract.
