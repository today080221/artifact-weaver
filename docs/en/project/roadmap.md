# Roadmap

## M0 Bootstrap

Create the Python-only repository, CLI, manifest contract, HTML report renderer, bilingual docs, fake examples, and worker harness.

## M1 Consumer Contract

Stabilize the downstream consumer contract for private projects that generate artifacts and call ArtifactWeaver.

## M2 Report Renderer Polish

Improve the static HTML report renderer, theme shape, accessibility, and artifact index.

## M3 Slides / PDF Renderer Evaluation

Evaluate optional Node, Vite, Slidev, or Playwright renderer backends without changing the Python core contract.
