# GitHub Seed

The GitHub repository, labels, milestones, and seed issues were created through GitHub CLI during M0 bootstrap.

If the seed ever needs to be recreated manually, use `gh label create`, `gh api repos/today080221/artifact-weaver/milestones`, and `gh issue create` with the labels, milestones, and issue titles listed in `docs/en/project/milestones.md` and the M0 handoff notes.
