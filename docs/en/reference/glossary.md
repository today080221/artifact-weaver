# Glossary

| Term | Meaning |
| --- | --- |
| Artifact | A source file or structured output rendered by ArtifactWeaver. |
| Evidence | Supporting assets referenced by a report. |
| Manifest | A JSON file that declares source artifacts and outputs. |
| Render Manifest | The ArtifactWeaver rendering contract. |
| Renderer | Code that turns artifacts into generated views. |
| Static HTML Report | A generated HTML report with no runtime service. |
| Slides | Future static presentation output. |
| Worker | A person or agent doing scoped work. |
| Worker Harness | Rules that constrain safe work. |
| Context Pack | A scoped work packet with allowed paths. |
| Scope | The work boundary for a task. |
| Boundary | A rule that separates source artifacts, generated views, and private data. |
| Consumer Contract | The agreement between downstream artifact producers and ArtifactWeaver. |
| Downstream Project | A private or public project that calls ArtifactWeaver. |
| CLI | Command-line interface. |
| JSON | JavaScript Object Notation. |
| Markdown | Plain-text markup format. |
| YAML | Future structured input format. |
| Git | Version control system. |
| GitHub | Hosted Git repository and issue platform. |
| Git LFS | Large file tracking extension for Git. |
| Node | Future optional runtime for renderer backends. |
| Bun | Future optional development runtime. |
