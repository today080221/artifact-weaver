# 范围

ArtifactWeaver 是通用的产物渲染中间件。

## M0 范围内

- 渲染清单 v1。
- Markdown 源文件。
- 报告 JSON 源文件。
- 证据资产 JSON 源文件。
- 单个静态 HTML 报告输出。
- 相对路径校验。
- 假数据示例。
- 双语文档和执行护栏体系。

## M0 范围外

- YAML 输入。
- 幻灯片。
- PDF 导出。
- Node、Bun、Vite、React、Vue 或 Slidev 渲染后端。
- Unity、飞书、Jenkins、Steam、Codex、MCP 或私有仓库集成。
- 测试执行、QA 判断或自动发现报告。
- NoTimeToDie 专用适配器代码。
