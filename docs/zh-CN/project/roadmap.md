# 路线图

## M0 Bootstrap

创建 Python-only 仓库、CLI、渲染清单契约、HTML 报告渲染器、双语文档、假数据示例和执行护栏体系。

## M1 Consumer Contract

稳定私有下游项目生成产物并调用 ArtifactWeaver 的消费方契约。

## M2 Report Renderer Polish

改进静态 HTML 报告渲染器、主题形态、可访问性和产物索引。

## M3 Slides / PDF Renderer Evaluation

评估可选的 Node、Vite、Slidev 或 Playwright 渲染后端，同时保持 Python 核心契约不变。
