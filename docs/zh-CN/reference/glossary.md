# 术语表

| 术语 | 含义 |
| --- | --- |
| 产物 | 由 ArtifactWeaver 渲染的源文件或结构化输出。 |
| 证据资产 | 报告引用的支持性资产。 |
| 渲染清单 | 声明源产物和输出的 JSON 文件。 |
| 渲染器 | 把产物转换成生成视图的代码。 |
| 静态 HTML 报告 | 不需要运行时服务的生成报告。 |
| 幻灯片 | 未来支持的静态演示输出。 |
| 执行者 | 执行受限任务的人或智能体。 |
| 执行护栏体系 | 约束安全工作的规则集合。 |
| 上下文包 | 带有允许路径和任务范围的工作包。 |
| 范围 | 某个任务的工作边界。 |
| 边界 | 区分源产物、生成视图和私有数据的规则。 |
| 消费方契约 | 下游产物生成方和 ArtifactWeaver 之间的约定。 |
| 下游项目 | 调用 ArtifactWeaver 的私有或公开项目。 |
| CLI | 命令行界面。 |
| JSON | 常用结构化数据格式。 |
| Markdown | 常用纯文本标记格式。 |
| YAML | 未来可能支持的结构化输入格式。 |
| Git | 版本控制系统。 |
| GitHub | Git 仓库托管和 issue 平台。 |
| Git LFS | Git 的大文件跟踪扩展。 |
| Node | 未来可选渲染后端可能使用的运行时。 |
| Bun | 未来可选的开发运行时。 |
